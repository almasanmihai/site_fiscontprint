# Fiscont Proiecte — fiscontprint.ro

Site static de prezentare pentru serviciile conexe Fiscont:

- Audit intern
- Reorganizare financiară
- Creare și setare departament financiar (inclusiv digitalizare)

Site-ul oficial de contabilitate rămâne [fiscontsrl.ro](https://fiscontsrl.ro/).

## Dezvoltare

```bash
npm install
npm run dev
```

## Build (pentru FTP / LiteSpeed)

```bash
npm run build
```

Vezi [DEPLOY.md](./DEPLOY.md) pentru pașii de upload.
